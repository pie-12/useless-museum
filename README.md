# useless-museum

[ Tiếng Việt ] | [ English ](./README.en.md) | [ 日本語 ](./README.ja.md)

---

Đây là 1 web bảo tàng vô dụng lấy cảm hứng từ The Useless Web.

---

### Chạy thử

Yêu cầu Node 18+.

```bash
git clone https://github.com/pie-12/useless-museum.git
cd useless-museum
npm install
npm run dev
```

Mở `http://localhost:3000`.

---

### Tech stack

Next.js 15, Tailwind, TypeScript. Không có backend phức tạp, mấy phòng realtime sau này xài Supabase / Upstash.
