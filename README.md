# useless-museum

Một cái web đóng vai bảo tàng chứa mấy thứ vô dụng. Bấm vào thì vui, không bấm thì cũng chẳng sao. Không giải quyết vấn đề gì của nhân loại cả.

Lấy cảm hứng từ The Useless Web.

---

### Mấy phòng đang có (và sắp có)

1. **Nút chả làm gì**: Bấm xong không có gì xảy ra. Thật đấy, chỉ có số nhảy lên thôi.
2. **Đồng hồ mơ hồ**: Chỉ nói kiểu "Gần trưa rồi", càng về chiều càng lười nói.
3. **Bộ đổi đơn vị vô dụng**: Đổi 5 km ra bao nhiêu ly trà đá với số lần bấm phím Space. Giao diện Win98.
4. **Máy tạo lý do trễ deadline**: Random lý do nghe cho đỡ ngại.
5. **Cà phê nguội**: Báo bao lâu nữa ly cà phê biến thành nước đắng.
6. **Chỗ ngồi duy nhất**: Cả thế giới mỗi lúc 1 người xem. Người sau đứng xếp hàng.
7. **Thú cưng ăn lỗi**: Cho pet ăn `console.error` để lớn lên.
8. **Đồng hồ cây số scroll**: Cuộn chuột xem bằng mấy lần cáp treo Bà Nà.
9. **Nhạc từ git history**: Biến commit thành nốt nhạc. Nghe hơi đau đầu.
10. **Bàn phím biết mệt**: Gõ nhanh quá bàn phím tụt máu rồi lăn ra ngất.
11. **Cây lớn khi bạn không làm gì**: Ngồi im thì cây sống. Động vào chuột là héo.
12. **Ngôn ngữ Quảng - Huế**: `răng` = if, `rứa` = then, `chừ` = print.
13. **Còi xe simulator**: Bấm còi đo độ mất kiên nhẫn khi kẹt xe.
14. **Chat một chữ**: Mỗi người góp đúng một từ viết truyện xàm.
15. **Trắc nghiệm bug**: Bạn là Null Pointer hay Race Condition.

### Chạy thử

Yêu cầu Node 18+.

```bash
git clone https://github.com/pie-12/useless-museum.git
cd useless-museum
npm install
npm run dev
```

Mở `http://localhost:3000`.

---

### Tech stack

Next.js 15, Tailwind, TypeScript. Không có backend phức tạp, mấy phòng realtime sau này xài Supabase / Upstash.
