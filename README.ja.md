# useless-museum

[ Tiếng Việt ](./README.md) | [ English ](./README.en.md) | [ 日本語 ]

---

The Useless Webにインスパイアされた、何の役にも立たない博物館のウェブサイトです。

---

### 起動方法

Node 18+ が必要です。

```bash
git clone https://github.com/pie-12/useless-museum.git
cd useless-museum
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

---

### 技術スタック

Next.js 15, Tailwind CSS, TypeScript。複雑なバックエンドはなく、リアルタイム機能はSupabase / Upstashを使用予定。
