A useless museum website inspired by The Useless Web.

---

### Getting Started

Requires Node 18+.

```bash
git clone https://github.com/pie-12/useless-museum.git
cd useless-museum
npm install
npm run dev
```

Open `http://localhost:3000`.

---

### Tech Stack

Next.js 15, Tailwind CSS, TypeScript. No complicated backend, realtime rooms will use Supabase / Upstash.
